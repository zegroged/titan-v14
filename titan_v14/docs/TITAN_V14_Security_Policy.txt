5. PORTLAR VE ARAYÜZLER
================================================================================

5.1 Veri Giriş (Data Input)
  - RED UART RX     : Plaintext veri girişi (PC'den)
  - BLACK UART RX   : Ciphertext veri girişi (kabloludan)
  - SPI MOSI        : 256-bit key injection

5.2 Veri Çıkış (Data Output)
  - RED UART TX     : Decrypted plaintext çıkışı (PC'ye)
  - BLACK UART TX   : Encrypted ciphertext çıkışı (kabloya)

5.3 Kontrol Giriş (Control Input)
  - KILL_PIN        : Fiziksel tamper tetikleme
  - JUMPER_CALIB    : Factory/Armed mod seçimi
  - COMM_MODE_PIN   : TX/RX mod seçimi
  - OMEGA_ENABLE    : DPA koruması açma/kapama
  - AEGIS_ENABLE    : AI anomaly tespit açma/kapama
  - SPI_CS_N/SCLK   : Key loading kontrol

5.4 Durum Çıkış (Status Output)
  - LED_STATUS_GREEN : Sistem hazır / heartbeat
  - LED_STATUS_RED   : Tamper alarm / kill aktif
  - LED_POST_FAIL    : POST self-test başarısız
  - LED_OMEGA_ACTIVE : DPA koruması aktif
  - PF_KILL_CMD     : PolarFire'a kill komutu

7. ANAHTAR YÖNETİMİ
================================================================================

7.1 Anahtar Türleri:
  ┌──────────┬─────────┬────────────┬──────────────────────────┐
  │ Anahtar  │ Uzunluk │ Depolama   │ Yaşam Süresi             │
  ├──────────┼─────────┼────────────┼──────────────────────────┤
  │ AES Key  │ 256-bit │ SRAM (vol) │ Key load → zeroize/power │
  │ eFUSE Key│ 256-bit │ eFUSE (OTP)│ Kalıcı (silinmez)        │
  │ Session  │ 32-bit  │ Register   │ Per-session (volatile)    │
  └──────────┴─────────┴────────────┴──────────────────────────┘

7.2 Anahtar Enjeksiyonu:
  - Yöntem: SPI (MOSI → key_loader_spi modülü)
  - 256 bit tek seferde yüklenir
  - Yükleme sırasında key_valid='0' → şifreleme engellenir
  - Yükleme tamamlanınca key_valid='1' → session_counter artar

7.3 Anahtar Silme (Zeroization):
  Tetikleyiciler (4 kaynak, OR mantığı):
    1. KILL_PIN      — Fiziksel tamper
    2. Watchdog      — PolarFire heartbeat kaybı
    3. AEGIS         — AI anomaly tespiti
    4. PVT           — Voltaj/sıcaklık saldırısı

  Silme Prosedürü:
    Stage 1: FDPE dead_latch SET (geri dönüşsüz)
    Stage 2: Tüm key register'lar <= x"00..00"
    Stage 3: Tüm data buffer'lar <= x"00..00"
    Stage 4: FSM'ler <= IDLE, key_valid <= '0'
    Süre: <1 clock cycle (asenkron)

9. FİZİKSEL GÜVENLİK
================================================================================

9.1 Tamper Response:
  - KILL_PIN → asenkron zeroization (<1 ns)
  - Dead latch (FDPE) → geri dönüşsüz, reset bile kurtarmaz
  - Factory mode: kill bypass (test ortamı)
  - Armed mode: kill aktif (production)

9.2 Bitstream Koruması:
  - AES-256 encrypted bitstream (eFUSE key)
  - JTAG readback disabled
  - Lab tools access disabled

9.3 Side-Channel Koruması:
  - Omega Cloak: Random stall injection (DPA koruması)
  - Shadow datapath: Dummy operations
  - Jittered clock: Opsiyonel

9.4 Çevresel Saldırı Tespiti:
  - PVT Monitor: ±10% voltaj/sıcaklık alarm
  - Clock glitch: PLL filter (system_supervisor)
  - Ring oscillator frequency monitoring

10. SONLU DURUM MODELİ
================================================================================

10.1 Sistem FSM:
  POWER_ON → POST_TEST → [PASS] → IDLE → KEY_LOADED → OPERATIONAL
                       → [FAIL] → HALTED (kalıcı)

  OPERATIONAL → KILL → ZEROIZED (geri dönüşsüz)

10.2 TX FSM (Full-Duplex):
  TX_IDLE → TX_COLLECT → TX_ENCRYPT → TX_WAIT_AES → TX_MAC_UPDATE
  → TX_WAIT_MAC → TX_NEXT_BLOCK → TX_SEND_SOF → TX_SEND_SEQ
  → TX_SEND_NBLK → TX_SEND_CT → TX_SEND_MAC → TX_DONE → TX_IDLE

10.3 RX FSM (Full-Duplex):
  RX_IDLE → RX_SYNC → RX_SEQ → RX_NBLK → RX_COLLECT_CT
  → RX_DECRYPT → RX_WAIT_AES → RX_MAC_UPDATE → RX_WAIT_MAC
  → RX_NEXT_BLOCK → RX_COLLECT_MAC → RX_CHECK_MAC → RX_OUTPUT
  → RX_DONE → RX_IDLE

10.4 Kill FSM:
  ALIVE → TRIGGERED → WIPE_KEYS → WIPE_DATA → DEAD (kalıcı)

11. WIRE FORMAT (Protokol Yapısı)
================================================================================

Tek Blok (16 byte payload):
  [SOF: 4B] [SEQ: 4B] [NBLK: 1B] [CT: 16B] [MAC: 16B] = 41 byte

Çoklu Blok (N × 16 byte payload, N=1..16):
  [SOF: 4B] [SEQ: 4B] [NBLK: 1B] [CT₁: 16B] ... [CTₙ: 16B] [MAC: 16B]
  Toplam: 4 + 4 + 1 + N×16 + 16 = 25 + N×16 byte

MAC Hesabı (CBC-MAC):
  Block₁: AES(Key, PT₁ ⊕ SeqNum ⊕ 0)
  Block₂: AES(Key, PT₂ ⊕ SeqNum ⊕ Block₁_MAC)
  ...
  Final MAC = son AES çıkışı (128-bit)
